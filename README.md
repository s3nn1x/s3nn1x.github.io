# Sennix

**Sennix is a Telegram bot developer and the author of Payload, a cybersecurity project. Creator of [@sennixbot](https://t.me/sennixbot).**

Sennix — разработчик Telegram-ботов и автор проекта Payload о кибербезопасности. Создатель @sennixbot.

## Проекты

- **[@sennixbot](https://t.me/sennixbot)** — бот для активной переписки в Telegram: ИИ-клон SNX.ai, сохранение удалённых и изменённых сообщений, скачивание медиа, генерация изображений, поиск музыки.
- **Payload** — кибербезопасность и IT в TikTok и Telegram: разборы реальных атак, инструменты, железо.
- **NFT gift tracker** — бот для отслеживания цен на NFT-подарки Telegram с уведомлениями.

## Стек
